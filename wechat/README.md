# 换的多 · 微信小程序版

和网页版功能一致：

- **汇率差计算**：选择持有和兑换的币种，输入金额和期望汇率，看现在换比目标多得还是少得多少。
- **全币种换算**：在任意一行输入金额，其他币种自动换算；点"编辑"可以调整顺序、移除币种，下方可添加 150 多种货币。
- 汇率缓存在手机本地；下拉页面可以手动刷新；支持深色模式和分享给好友。

## 目录结构

```

```

## 汇率数据

使用 [极速数据](https://www.jisuapi.com/api/exchange/) 的汇率查询接口免费版，不需要服务器或云开发，不产生费用。

- 一次请求返回以美元为基准的 150 多种货币汇率，其他币种之间用交叉汇率计算。
- 免费额度为**所有用户每天共 100 次**。小程序把汇率缓存在手机上，每台手机大约 12 小时请求一次；手动刷新至少间隔 1 小时。大约够每天 100 人左右使用，用户更多时需要升级极速数据会员，或改用云开发方案。
- AppKey 写在 `miniprogram/config.js` 里，会随小程序一起发布，无法完全隐藏。免费版额度被用完只会让当天无法刷新，不会产生费用，所以**极速数据账户里不要充值**。
- 极速数据要求在申请后 14 天内完成实名认证，否则会影响使用。

## 发布前需要在小程序后台完成

1. **服务器域名**：在"开发管理 → 开发设置 → 服务器域名"的 request 合法域名里添加 `https://api.jisuapi.com`。不加的话，真机上会请求失败。
2. **小程序备案**：上架前必须完成。
3. **用户隐私保护指引**：在"设置 → 服务内容声明"里填写。本小程序不收集个人信息，设置和汇率只保存在用户手机本地。

## 测试与发布

1. 用微信开发者工具导入 `wechat` 文件夹，点"编译"，模拟器里应显示"汇率更新于 ……"。
2. 点"预览"，用手机微信扫码在真机上试用。
3. 点"上传"，再到后台"版本管理"里设为体验版或提交审核，审核通过后发布。

## 常见问题

- **显示"今天的汇率查询次数已用完"**：免费额度 100 次/天用完了，第二天自动恢复。
- **真机上显示"网络连接失败"，模拟器正常**：检查是否在后台添加了 `https://api.jisuapi.com` 服务器域名。
- **想改默认币种**：修改 `miniprogram/config.js` 里的 `DEFAULTS` 和 `COMMON`。
