# 汇率换算 · 微信小程序版

和网页版功能一致：

- **汇率差计算**：选择持有和兑换的币种，输入金额和期望汇率，看现在换比目标多得还是少得多少。
- **全币种换算**：在任意一行输入金额，其他币种自动换算；点"编辑"可以调整顺序、移除币种，下方可添加 160 多种货币。
- 汇率缓存在手机本地，到下次更新时间才重新获取；下拉页面可以手动刷新；支持深色模式和分享给好友。

## 目录结构

```
wechat/
├── project.config.json        开发者工具的项目配置（导入时会填入你的 AppID）
├── cloudfunctions/getRates/   云函数：用 API Key 获取汇率，结果缓存在云数据库
└── miniprogram/
    ├── app.js / app.json / app.wxss / theme.json
    ├── config.js              云开发环境 ID、默认币种
    ├── utils/currency.js      币种中文名、国旗、小数位、数字格式化
    ├── utils/rates.js         调用云函数、本地缓存、交叉汇率
    └── pages/index/           页面
```

## 为什么用云函数

小程序直接请求的网址必须是做过 ICP 备案的国内域名，网页版用的 Cloudflare 中转不符合要求。云函数运行在微信的云开发环境里，由它去请求 ExchangeRate-API，小程序只调用云函数，不需要配置域名。API Key 保存在云函数的环境变量里，用户看不到。

云函数会把汇率存进云数据库，到数据源下次更新前都直接返回缓存，所以无论多少人使用，每天只会请求 ExchangeRate-API 一两次。可以和网页版共用同一个 Key。

## 第一步：注册小程序

1. 打开 [微信公众平台](https://mp.weixin.qq.com)，点"立即注册"，选择"小程序"。个人身份也可以注册。
2. 注册完成后登录后台，在"开发管理 → 开发设置"里找到 **AppID**。
3. 在"设置 → 基本设置"里填写小程序名称、头像和简介。名称需要全网唯一，例如"汇率换算助手"。
4. 服务类目选择"工具"大类下合适的类目。不要选金融类，金融类需要相关资质。

## 第二步：导入项目

1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版）。
2. 选择"导入项目"，目录选本仓库的 `wechat` 文件夹，AppID 填第一步拿到的，后端服务选"微信云开发"。

## 第三步：开通云开发并部署云函数

1. 在开发者工具顶部点"云开发"，按提示开通并创建一个环境。云开发按套餐付费，价格以官方页面为准。
2. 在左侧文件树里右键 `cloudfunctions/getRates`，选择 **"上传并部署：云端安装依赖"**。
3. 在云开发控制台进入"云函数 → getRates"，在函数配置里添加环境变量：
   - 名称：`EXCHANGE_RATE_API_KEY`
   - 值：你的 ExchangeRate-API Key
4. 云数据库的 `rates_cache` 集合会在第一次运行时自动创建，不需要手动建。

如果有多个云开发环境，把正式环境的 ID 填进 `miniprogram/config.js` 的 `CLOUD_ENV`。

## 第四步：测试

1. 在开发者工具里点"编译"，模拟器里应显示"汇率更新于 ……"和当前汇率。
2. 点"预览"，用手机微信扫码在真机上试用。
3. 想让家人朋友先试用：上传代码后，在后台"版本管理"里把它设为体验版，并在"成员管理"里添加体验成员。

## 第五步：备案、审核与发布

1. **小程序备案**：按照国家规定，小程序上架前需要完成备案。在小程序后台按提示填写主体和负责人信息、上传证件，提交后等待审核。
2. **用户隐私保护指引**：在后台"设置 → 服务内容声明"里填写。本小程序不收集任何个人信息，设置和汇率只保存在用户手机本地，按实际情况如实填写即可。
3. **上传代码**：在开发者工具右上角点"上传"，填写版本号和备注。
4. **提交审核**：在后台"版本管理"里把开发版提交审核，审核通过后点"发布"。

## 常见问题

- **显示"汇率服务还没有配置好"**：云函数没有找到环境变量 `EXCHANGE_RATE_API_KEY`，检查第三步。
- **显示"暂时连不上汇率服务"**：确认云函数已经部署，并且 `config.js` 里的环境 ID（如有填写）正确。
- **想改默认币种**：修改 `miniprogram/config.js` 里的 `DEFAULTS` 和 `COMMON`。
